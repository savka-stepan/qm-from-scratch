# Код до курсу «Квантова механіка з нуля»

Приклади з епізодів: одна тека — один епізод.

## Без встановлення

Інтерактивні сторінки з повзунками відкриваються просто в браузері, і на телефоні теж:

- [Епізод 1 «Що таке хвиля»](https://savka-stepan.github.io/qm-from-scratch/ep01/)

## Запуск коду

Потрібен [uv](https://docs.astral.sh/uv/getting-started/installation/) — він сам поставить
Python і бібліотеки (numpy, matplotlib) під час першого запуску:

```bash
uv run ep01/travelling_wave.py
```

## Епізоди

Усі графіки беруть спільний темний стиль у кольорах відео з `course.mplstyle`.


- `ep01/travelling_wave.py` — хвиля, що біжить, y = A·sin(kx − ωt), і розрахунок v = λ·f
  (нота «ля» 440 Гц, зелене світло 550 нм). Амплітуду, довжину хвилі й частоту міняють
  повзунки під графіком.
- `ep01/index.html` — та сама хвиля на вебсторінці (повзунки, «зупинити час», калькулятор v = λ·f).
